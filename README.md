## ▶️ Compiling C Programs

Using GCC:

```bash
gcc program.c -o program
```

Run the program:

```bash
./program
```

## ▶️ Compiling C++ Programs

Using G++:

```bash
g++ program.cpp -o program
```

Run the program:

```bash
./program
```
